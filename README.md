# 🚀 enumservice

> API gateway for microservices

## ✨ Features

- Fast compilation (sub-second builds)
- Hot reload included
- Plugin system
- Zero config start

## 📦 Installation

```bash
npm install -g enumservice
enumservice init my-project
```

## 🛠️ Stack

Built with observer.js + Bump all versions to 0.6.20
